Fling

Inductive Graph Layout with Implicit Neural Fields

Berfin Inal · Daniel Probst

Paper · Code · PyPI

Stress-based and force-directed layout methods treat the coordinates of the N nodes as free parameters and optimise them directly. The resulting layout is transductive, defined only for the nodes present during optimisation, and incorporating new nodes requires re-optimisation, which in general does not preserve the existing drawing. We introduce Fling (Field Layout via Implicit Neural Geometry), which instead parameterises the layout as an implicit neural field, in which a coordinate network Φθ maps a structural feature vector fv of each node to its position, pv = Φθ(fv) ∈ ℝ2. The weights θ are fitted to the layout energy of a single input graph, and the fitted field is inductive, assigning positions to nodes that were not observed during fitting.

Contributions

  1. Layout as an inductive field. A node that was not seen during fitting is placed by evaluating Φθ once, with no re-optimisation. Nodes already drawn move only as far as their own features change when the graph grows, so the existing drawing is largely preserved. Because the parameters are a fixed set of network weights rather than one coordinate pair per node, the model size is independent of the size of the graph, and the weights can be fitted on a sample of the nodes. Among methods that can place unseen nodes in this way, the fitted field outperforms PivotMDS, landmark MDS and kernel ridge regression on the same node features.
  2. Training without the O(N2) sum over node pairs. Layout energies such as stress compare every pair of nodes, so a single evaluation costs O(N2). Each variant avoids this cost. Fling computes the exact pairwise terms only at m ≪ N anchor nodes and fits a second, auxiliary network Φ̃ψ that extends them to all nodes, so a training step costs O(mN). The stress and neighbour-embedding variants evaluate their energies on random subsets of node pairs instead. The auxiliary network is used only during training, and placing a node always requires Φθ alone.

Method

Each node is first described by how easily it is reached from a few landmark nodes spread across the graph. From every landmark, a random walk moves along the edges and returns to the landmark with a fixed probability at each step, so it mostly stays in the landmark's neighbourhood. Nodes near a landmark are visited often and distant nodes rarely, and the visit frequencies to all landmarks, on a logarithmic scale, form the feature vector fv. The landmarks are chosen once, at fitting time, so a new node is described with respect to the same landmarks as the nodes already drawn. All variants share this input and the coordinate network Φθ, and differ only in the energy on which the weights are trained, namely all-pairs stress majorisation (Fling), scale-normalised pivot stress (FlingStress), or a neighbour-embedding energy with sampled negatives plus node–edge and crossing terms (FlingVis). Because the features are defined for every node of the graph, the fitted field can be evaluated on nodes outside the training set.

Variants

All variants read the same diffusion potentials \(f_v\) and train the same coordinate network \(\Phi_\theta\); they differ only in the energy on which the weights are trained. None of them evaluates the \(O(N^2)\) pair sum. After training, an unseen node \(v^\star\) is placed by one forward pass, \(x_{v^\star} = \Phi_\theta(f_{v^\star})\).

Below the explanations, every variant draws six graphs from the paper's benchmark, two chosen to show the strength of each variant; reading down a column compares the variants on the same graph. Under each drawing are the normalised stress (lower is better) and the neighbourhood preservation, NP (higher is better), for a single seed; the best value of the measure each column is about is highlighted.

Fling

Kamada–Kawai stress, by majorisation

Each step evaluates the exact pair term at \(m \ll N\) sampled anchors, fits a secondary, training-time field \(\widetilde{\Phi}_\psi\) to these values, and queries it at every node, so a step costs \(O(mN)\). The field plays the role of a Barnes–Hut far field, without the tree. Rest lengths come from the pivot bound \(r_{ij} = \max_s |h_{is} - h_{js}|\) over the hop distances \(h_i \in \mathbb{R}^p\) to \(p\) farthest-first pivots, so no distance matrix is ever formed.

FlingStress

Scale-normalised pivot stress

Trains the network to reproduce shortest-path distances to \(|Q| \ll N\) uniformly sampled pivots, with the graph edges as unit-length targets for local fidelity,

\[ \begin{aligned} \mathcal{L}_{ST} = \frac{1}{|\mathcal{T}| + |E|}\Big[ &\sum_{(v,j)\in\mathcal{T}}\Big(\frac{a\,e_{vj} - \Delta_{vj}}{\Delta_{vj}}\Big)^2 \\ &+ \sum_{(u,w)\in E}\big(a\,e_{uw} - 1\big)^2\Big] \end{aligned} \]

The scale \(a\) minimises the bracket in closed form and is refitted at every step. The pivot sum runs over batches of \(\min(128, |Q|)\) columns, and the result matches sgd² to within a few percent.

FlingVis

Neighbour embedding with legibility terms

A neighbour-embedding energy over the edges and uniformly sampled non-adjacent pairs \(\mathcal{N}\), with the attraction exaggerated over the first third of training,

\[ \begin{aligned} \mathcal{L}_{NE} = {}&\frac{1}{|E|}\sum_{(u,v)\in E}\log\big(1 + e_{uv}^2\big) \\ &- \frac{1}{|\mathcal{N}|}\sum_{(u,v)\in\mathcal{N}}\log\frac{e_{uv}^2}{1 + e_{uv}^2} \end{aligned} \]

A second phase adds node–edge clearance, \(\mathrm{relu}(1 - d_{v,uw}/c\ell)^2\), and a differentiable crossing count, \(\chi = \sigma(-d_1 d_2/\tau)\,\sigma(-d_3 d_4/\tau)\), each evaluated on the \(\kappa\)-nearest candidates of \(m'\) sampled nodes or edges at \(O(\kappa m')\) per step.

One field for a continuum of objectives (FlingBlend)

For a blended energy \(\mathcal{L}(\lambda) = (1-\lambda)\,\mathcal{L}_A + \lambda\,\mathcal{L}_B\), the network receives \(\lambda\) as a second input, \(\Phi_\theta(f_v, \lambda)\), resampled at every step from a \(\mathrm{Beta}(\tfrac12, \tfrac12)\) prior that keeps weight on both endpoints. \(\lambda\) enters as Fourier features that modulate the hidden layers through learned per-channel gains and shifts, rather than as one more input number, which the network tends to underuse. The whole continuum \(\lambda \in [0, 1]\) is then a single function, and the drawings for different \(\lambda\) share one coordinate frame with no alignment step.

Demonstrations

Training on a sample, placing the rest

Because the unknowns are the network weights rather than one coordinate per node, the energy can be evaluated on a random sample of the nodes. FlingStress is trained on nested samples of between 2% and 100% of the nodes, and each time the trained model places every node of the graph, including all those outside the sample. The drawings are rotated onto the one trained on all nodes, which changes only the viewpoint.

Placing new entries as a database grows

Biological data keeps arriving, and a map of it is only useful if new entries can be added without redrawing it. We take three examples, protein domains from the PDB by year of deposition, classified by CATH and linked by structural similarity, ligands of six protein targets from ChEMBL by year of publication, linked by chemical similarity, and single blood cells from eight donors, linked by similarity of gene expression, where a reference of two donors is extended one donor at a time, as in mapping new samples onto a cell atlas. In each, FlingVis is fitted once to the first entries, and each later batch is embedded with Φθ held fixed. As the graph grows, the diffusion features of existing nodes change as well; each batch is therefore registered to the fitted layout by a single affine transformation, estimated by least squares on the training entries, and entries placed earlier keep their positions.

The small dots are the entries the model was trained on, one colour per class. The entries of the selected period are drawn larger, in the colour of their own class, so a correct placement puts each one among the training entries of its colour. Pointing at a new entry draws its links to the earlier entries it is most similar to; it is placed near them because its diffusion features, computed from those links, resemble theirs. Measured as the share of each new entry's ten nearest training entries in the same class, placement in this dataset stays between 0.7 and 0.85 in every batch, against a chance level of 0.2.

Blending two energies

FlingBlend conditions the field on a mixing weight λ ∈ [0, 1], giving Φθ(fv, λ), and is trained on the convex combination (1 − λ) Estress + λ ENE of normalised stress, which preserves graph-theoretic distances, and a neighbour-embedding objective, which preserves local neighbourhoods. A single fit therefore yields a continuous family of layouts, each obtained by one forward pass.
